# 입력값을 미리 보여주는 메시지 전송기

입력 중인 메시지를 화면에 표시하고, 전송 버튼으로 확인하는 `MessageTelautograph` 컴포넌트를 구현하라.

## 구현할 내용

- 제목은 `메시지 전송기`, 입력란의 안내 문구는 `메시지를 입력하세요`, 버튼 문구는 `전송`으로 한다.
- 입력란 아래에 `미리보기: `와 현재 입력값을 표시한다. 글자를 입력하거나 지우면 미리보기도 함께 바뀌어야 한다.
- 전송 버튼을 누르면 현재 메시지를 `alert`로 표시한다. 알림창을 닫으면 입력값과 미리보기 내용을 비운다.
- 빈 입력도 그대로 전송할 수 있게 한다. 서버로 전송하는 기능은 요구하지 않는다.

## 작성할 파일과 제약사항

- `../MessageTelautograph.jsx`에 같은 이름의 함수 컴포넌트를 작성하고 기본 내보내기한다.
- `useState`로 초기값이 빈 문자열인 `message` 상태를 만든다.
- `value`와 `onChange`를 연결한 제어 입력을 사용한다. `handleChange`에서 이벤트의 `target.value`로 상태를 갱신한다.
- `btnClick`에서 메시지 표시와 상태 초기화를 순서대로 수행한다.
- `<div>` 안에 `<h1>`, 텍스트 `<input>`, `<button>`, 미리보기 `<p>`를 배치한다.

## 실행 결과 확인

`안녕하세요` 입력 → `미리보기: 안녕하세요` 확인 → 전송 → 같은 내용의 알림 확인 → 알림창 닫기 → 입력란과 미리보기 내용이 비워지는지 확인하라.
