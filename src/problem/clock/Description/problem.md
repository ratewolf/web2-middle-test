# 현재 시간을 표시하는 시계

현재 시각을 1초 간격으로 갱신하는 `Clock` 컴포넌트를 구현하라.

## 구현할 내용

- 처음 표시될 때 현재 날짜와 시간을 가져온다.
- 시·분·초를 24시간제 `HH:MM:SS` 형식으로 표시한다. 한 자리 수 앞에는 `0`을 붙인다. 예: `09:05:03`, `18:30:12`.
- 약 1초마다 현재 날짜와 시간을 새로 읽어 화면을 갱신한다. 초를 단순히 1씩 더하는 방식은 사용하지 않는다.
- 시계가 화면에서 제거되면 등록한 타이머도 해제한다.

## 작성할 파일과 제약사항

- `../Clock.jsx`에 함수 컴포넌트 `Clock`을 작성하고 기본 내보내기한다.
- `useState`에 초기화 함수를 전달하여 최초 상태를 `Date` 객체로 만든다.
- 의존성 배열이 빈 배열인 `useEffect` 안에서 `setInterval`을 등록하고, 정리 함수에서 `clearInterval`을 호출한다.
- `getHours()`, `getMinutes()`, `getSeconds()`로 값을 구하고, `String`과 `padStart`로 각각 두 자리 문자열을 만든다.
- 템플릿 리터럴로 시간 문자열을 만들고, `<div>` 안의 `<time>` 요소에 표시한다.

## 실행 결과 확인

- 실행한 컴퓨터의 현지 시각과 비교하고, 몇 초 동안 값이 바뀌는지 확인한다.
- 표시 예: `09:05:03` → `09:05:04` → `09:05:05`. 실제 시작 시각은 실행 시점에 따라 달라진다.
- 개발 환경의 `StrictMode`에서는 Effect 설정·정리가 추가로 실행될 수 있다. 정리 함수를 작성하여 타이머가 중복으로 남지 않게 한다.
