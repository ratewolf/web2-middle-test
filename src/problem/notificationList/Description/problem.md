# 알림 목록과 클래스 컴포넌트의 생명주기

3초 간격으로 알림을 하나씩 추가하고, 콘솔에서 자식 컴포넌트의 생명주기를 관찰하라.

## 구현할 내용

- 처음에는 알림이 없는 빈 목록을 표시한다.
- 마운트된 후 약 3초마다 다음 알림을 한 개씩 순서대로 추가한다. 기존 알림은 유지한다.

| id | message |
| --- | --- |
| 1 | 안녕하세요, 여러분. 반갑습니다! |
| 2 | 오늘은 10월을 시작하는 날입니다. |
| 3 | 오늘 기분은 어떠신가요? |
| 4 | 만약 우울하시다면 기분 전환을 위해 독서는 어떨까요? |
| 5 | 내일은 더 좋은 날이 될거라고 믿어요! |

- 다섯 개를 모두 추가한 뒤 다음 타이머 콜백에서 반복을 종료한다. 컴포넌트가 먼저 제거되면 그때도 타이머를 해제한다.
- 각 `Notification`은 전달받은 메시지를 `<div>` 안의 `<span>`에 표시한다.
- `Notification`의 마운트·업데이트·언마운트 시 각각 `아이디: componentDidMount Called`, `아이디: componentDidUpdate Called`, `아이디: componentWillUnmount Called`를 콘솔에 출력한다.

## 작성할 파일과 제약사항

- `../NotificationList.jsx`, `../Notification.jsx`에 각각 파일과 같은 이름의 클래스 컴포넌트를 작성하고 기본 내보내기한다. `React.Component`를 상속한다.
- `NotificationList`에서 표의 데이터를 `reservedNotifications` 배열로 준비하고, `this.state.notifications`의 초기값을 빈 배열로 설정한다.
- `componentDidMount`에서 `setInterval`을 등록한다. 현재 목록 길이를 다음 데이터의 인덱스로 사용하고, 알림을 추가한 뒤 `this.setState`로 화면 갱신을 요청한다.
- `render`에서 `map`을 사용하고, 자식에 `key`, `id`, `message`를 전달한다. `key`는 React가 사용하는 값이므로 자식이 읽을 `id`도 별도로 전달해야 한다.
- `componentWillUnmount`에서 타이머를 해제한다.

## 실행 결과 확인

한 번의 마운트를 기준으로 약 3초 후 첫 알림, 약 15초 후 다섯 알림이 모두 표시되는지 확인하라. 기존 자식의 업데이트와 새 자식의 마운트 로그를 관찰하고, 목록을 화면에서 제거하면 언마운트 로그가 남는지 확인한다.

개발 환경의 `StrictMode`에서는 생명주기 호출과 로그가 추가로 발생할 수 있다. 정답은 모듈 범위 타이머와 배열 직접 변경을 사용하는 수업 예제이므로, 해당 환경에서 로그 횟수나 추가 순서가 위의 단일 마운트 예시와 다를 수 있다. 단순한 부모 재렌더링은 언마운트와 다르다.
