# 클릭할 때마다 상태가 바뀌는 토글 버튼

버튼을 누를 때마다 `켜짐`과 `꺼짐`을 번갈아 표시하는 토글 버튼을 구현하라.

## 구현할 내용

- 최초 상태는 `true`이며 버튼에 `켜짐`을 표시한다.
- 클릭할 때마다 이전 상태의 논리값을 반전한다.
- 상태가 `true`이면 `켜짐`, `false`이면 `꺼짐`을 표시한다.

## 작성할 파일과 제약사항

- `../ToggleButton.jsx`에 먼저 함수 컴포넌트 방식으로 구현하고 기본 내보내기한다. 함수형 정답의 컴포넌트 이름은 `ToggleFunction`이다.
- `useState`로 `isToggleOn`을 관리하고, `handleClick`에서 이전 상태를 받는 함수형 업데이트를 사용한다.
- 삼항 연산자로 버튼 문구를 결정하고, `onClick`에는 처리 함수 자체를 전달한다.
- 같은 파일을 클래스 컴포넌트 방식으로도 바꾸어 연습하라. 클래스형 정답의 이름은 `ToggleButton`이며, 두 방식은 한 번에 하나씩 실행하여 비교한다.
- 클래스 방식에서는 `React.Component`를 상속하고, 생성자에서 `super(props)`, 초기 상태 설정, `handleClick`의 `this` 바인딩을 수행한다. `this.setState`에 이전 상태를 받는 함수를 전달하고, `render`에서 `<div>` 안에 버튼을 표시한다.

## 실행 결과 확인

처음 `켜짐` → 한 번 클릭 `꺼짐` → 두 번 클릭 `켜짐`인지 확인하라. 함수형과 클래스형 모두 같은 순서로 바뀌어야 한다.
