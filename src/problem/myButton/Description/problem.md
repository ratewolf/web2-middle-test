# 클릭 이벤트와 상태 업데이트 관찰하기

클릭할 때마다 번호와 이벤트 정보를 콘솔에 출력하는 `MyButton` 컴포넌트를 구현하라.

## 구현할 내용

- `버튼을 클릭하세요. (결과를 보려면 개발자 도구(F12) 실행)`이라는 버튼을 표시한다.
- `count` 상태의 초기값은 `1`로 한다.
- 클릭하면 함수형 업데이트로 `count`를 1 증가시키고, 이어서 `btnClick(count, event)`를 호출한다.
- `btnClick(id, event)`는 `id`, `event.target`, `event.x`, `event.y`를 이 순서로 `console.log`에 전달한다.
- 클릭 번호는 화면에 추가로 표시하지 않는다.

## 작성할 파일과 제약사항

- `../MyButton.jsx`에 함수 컴포넌트 `MyButton`을 작성하고 기본 내보내기한다.
- `useState`를 사용하고, `onClick`의 화살표 함수에서 이벤트 객체를 받아 처리 함수에 전달한다.
- 상태를 업데이트한 직후에도 현재 이벤트 처리 함수에서 읽는 `count`는 해당 렌더링의 값이다. 첫 클릭에는 `1`, 다음 클릭에는 `2`가 출력되도록 한다.

## 실행 결과 확인

개발자 도구의 콘솔을 열고 버튼을 세 번 눌러 첫 번째 출력값이 `1`, `2`, `3`인지 확인하라. `event.target`은 클릭한 요소를 나타낸다. 기존 정답이 읽는 `event.x`, `event.y`는 환경에 따라 `undefined`일 수 있으므로 좌표 숫자가 반드시 나온다고 가정하지 않는다.
