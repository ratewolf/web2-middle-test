# props로 도서 정보 전달하기

도서 한 권을 표시하는 `Book`과 이를 재사용하는 `Library` 컴포넌트를 구현하라.

## 구현할 내용

- `Book`은 `name`과 `numOfPage`를 props로 받는다.
- `<h1>`에는 `이 책의 이름은 도서명입니다.`를, `<h2>`에는 `이 책은 총 페이지수페이지로 되어있습니다.`를 표시한다.
- `Library`는 다음 순서대로 세 권을 표시한다.

| name | numOfPage |
| --- | --- |
| 처음 만난 Java | 300 |
| 난생 처음 자바 | 200 |
| 처음 보는 React | 500 |

## 작성할 파일과 제약사항

- `../Book.jsx`: 함수 컴포넌트 `Book`을 작성하고 기본 내보내기한다. `<div>` 안에 두 제목을 배치하고, 템플릿 리터럴로 props를 문장에 삽입한다.
- `../Library.jsx`: 함수 컴포넌트 `Library`를 작성하고 기본 내보내기한다. `Book`을 가져와 `<div>` 안에서 세 번 사용한다.
- 도서명은 문자열로, 페이지 수는 중괄호를 사용한 숫자로 전달한다. `Book` 안에 특정 도서 정보를 고정하여 작성하지 않는다.

## 실행 결과 확인

첫 번째 도서에 `이 책의 이름은 처음 만난 Java입니다.`와 `이 책은 총 300페이지로 되어있습니다.`가 표시되는지 확인한다. 나머지 두 권도 표의 값과 순서대로 표시되어야 한다.
