# 수용인원 관리와 사용자 정의 훅

최대 20명까지 입장할 수 있는 시설의 수용인원을 관리하라. 컴포넌트에서 직접 상태를 관리하는 방식과 사용자 정의 훅(Custom Hook)을 사용하는 방식으로 각각 구현하라.

## 구현할 내용

- 처음에는 `현재 수용인원: 0/20`을 표시한다.
- `수용시설에 입장` 버튼을 누르면 1명 증가하고, `수용시설에서 퇴장` 버튼을 누르면 1명 감소한다.
- 0명일 때는 퇴장 버튼을, 20명일 때는 입장 버튼을 비활성화한다.
- 20명일 때만 `수용시설에 정원이 가득 찼습니다.`를 표시한다. 19명으로 줄면 문구가 사라지고 입장 버튼이 다시 활성화되어야 한다.
- 인원 변경 함수에서도 값이 0보다 작아지거나 20보다 커지지 않도록 제한한다.

## 작성할 파일과 제약사항

- `../withoutCustomHook/Accommodate.jsx`: `useState`로 인원을 관리하고, 입장·퇴장 함수를 컴포넌트 안에 작성한다.
- `../withCustomHook/useCounter.jsx`: `useCounter(initialValue, MAX_CAPACITY)` 훅을 작성한다. 현재 인원, 증가 함수, 감소 함수를 이 순서의 배열로 반환한다. 함수형 업데이트와 `Math.min`, `Math.max`로 범위를 제한한다.
- `../withCustomHook/Accommodate.jsx`: `useCounter(0, MAX_CAPACITY)`로 인원을 관리한다. 정원 도달 여부는 별도 상태로 두고, 인원이 바뀔 때 실행되는 `useEffect`에서 갱신한다. 이 Effect에서 콘솔에 `Current Count Value: 현재인원`도 출력한다.
- 두 컴포넌트의 이름과 기본 내보내기는 `Accommodate`로 한다. 두 방식의 화면과 버튼 동작은 같아야 한다.
