# 항목을 추가하고 삭제하는 목록

입력한 항목을 목록에 추가하고, 더블클릭으로 삭제하는 `TodoListApp`을 구현하라.

## 구현할 내용

- 제목은 `My Groceries`, 입력란의 안내 문구는 `Add a new item...`, 버튼 문구는 `Add Task`로 한다.
- 초기에는 입력란과 목록이 모두 비어 있다.
- 버튼을 누르거나 입력란에서 Enter를 누르면 입력값을 목록 끝에 추가하고 입력란을 비운다.
- 빈 문자열이나 공백만 입력한 경우 추가하지 않는다. 유효한 입력은 원래 문자열 그대로 저장한다. 예를 들어 ` 우유 `의 양쪽 공백은 저장 시 제거하지 않는다.
- 각 항목을 더블클릭하면 해당 위치의 항목 하나만 삭제한다. 마우스를 올리면 `더블클릭하여 삭제`라는 안내가 표시되어야 한다.
- 같은 문구의 항목도 여러 번 추가할 수 있다.

## 작성할 파일과 제약사항

- `../TodoListApp.jsx`에 같은 이름의 함수 컴포넌트를 작성하고 기본 내보내기한다.
- `useState`로 배열 `todos`와 문자열 `input`을 각각 관리한다.
- `handleAddTask`는 `trim()`으로 공백 여부를 검사하고, 전개 구문으로 새 배열을 만들어 추가한다.
- 입력란의 `value`와 `onChange`를 상태에 연결한다. `handleKeyDown`에서 `e.key`가 `Enter`이면 추가 함수를 호출한다.
- `map`으로 `<ul>` 안의 `<li>`들을 만들고, 정답과 같이 배열 인덱스를 `key`와 삭제 대상 식별에 사용한다.
- `handleDeleteTask(indexToDelete)`는 `filter`로 해당 인덱스를 제외한 새 배열을 만들고 상태를 갱신한다.

## 실행 결과 확인

버튼으로 `우유` 추가 → Enter로 `빵` 추가 → 공백만 입력하여 추가되지 않는지 확인 → `우유` 더블클릭으로 삭제 순서로 확인하라. 같은 문구를 두 번 추가한 뒤 하나만 삭제되는지도 확인한다.
